A one-page newspaper front page summing up Wednesday 18 November 2026's world news: APEC opens in Shenzhen ahead of the first Trump–Xi–Putin summit, Cyclone Akvan bears down on Andhra Pradesh, Estonia moves to shut its Russia border, and MS Dhoni retires from the IPL. `draw_frontpage.py` draws the page from the day's verified headlines; `main.py` (Python 3.13, standard library only) copies the finished `entry.png` to the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
